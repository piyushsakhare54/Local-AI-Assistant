# Security and privacy

- The API binds to loopback and only allows the local desktop development origins.
- The renderer has Node integration disabled, context isolation enabled, and a sandboxed preload. No general Node API is exposed to the UI.
- No remote inference endpoints are configured. Whisper weights are downloaded only when transcription is requested and the weights are not already cached. Ollama and its model are installed explicitly by the user.
- User data and model weights are excluded from Git.
- Microphone capture requires an explicit user action and shows a visible recording state. Audio uploads are capped at 25 MB; recordings are held in memory and discarded after transcription, while recognized transcript text is persisted in SQLite.
- PDF summaries are generated by the local AI and saved to a user-selected path on this device. The PDF export bridge exposes only this save operation to the renderer.
- Do not log transcript or prompt content. Database encryption and secure secret storage are not configured.
